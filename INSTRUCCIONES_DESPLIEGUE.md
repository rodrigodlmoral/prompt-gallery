# CÓMO PONER TU WEB EN INTERNET (LEER AQUI)

Hola! Entiendo que la pantalla negra (Terminal) puede ser confusa. Aquí tienes la guía definitiva.

## PASO 1: ENCONTRAR LA TERMINAL
Mira la parte de **ABAJO** de esta ventana donde escribes código.
Deberías ver una pestaña que dice **"TERMINAL"**.
Haz clic ahí. Debería aparecer un cursor parpadeando donde puedes escribir.

## PASO 2: EL COMANDO MÁGICO
Haz clic en esa zona negra para asegurarte que estás escribiendo ahí.
Escribe esto y pulsa la tecla **ENTER**:

vercel

## PASO 3: RESPONDER A TODO QUE SÍ
Te van a salir preguntas en inglés.
Simplemente pulsa la tecla **ENTER** cada vez que pare de escribir, hasta que termine.

1.  Set up and deploy? -> **ENTER**
2.  Which scope? -> **ENTER**
3.  Link to existing project? -> **ENTER**
4.  What’s your project’s name? -> **ENTER**
5.  In which directory? -> **ENTER**

## PASO 4: ¡LISTO!
Al final te dará un enlace azul (https://...). **Esa es tu web.**
Copialo y ábrelo en tu navegador.
